# Demo-Tracker Sample Placeholders

Add the following audio sample files (16-bit WAV recommended) to this folder so the Demo-Tracker can load them at runtime:

- `synth-lead.wav` — Bright saw lead at middle C.
- `synth-bass.wav` — Deep rounded triangle bass at middle C (C2 suggested).
- `synth-pad.wav` — Warm analog pad.
- `synth-arp.wav` — Plucky arpeggiator sound.
- `vocal-yeah.wav` — Synthetic vocal "Yeah" hit.
- `vocal-hey.wav` — Synthetic vocal "Hey" hit.
- `fx-impact.wav` — Heavy cinematic impact.
- `fx-sweep.wav` — White noise rising sweep.
- `drum-kick.wav` — Punchy kick drum.
- `drum-snare.wav` — Snare with noise snap.
- `drum-clap.wav` — Layered clap sample.
- `drum-hat-c.wav` — Tight closed hi-hat.
- `drum-hat-o.wav` — Open hi-hat.
- `drum-tom-h.wav` — High rack tom.
- `drum-tom-l.wav` — Low floor tom.
- `drum-cymbal.wav` — Long ride cymbal.

Ensure each file name matches exactly so the tracker configuration in `config/config.json` can locate the samples.
